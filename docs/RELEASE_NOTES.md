IRON//VEIL v0.1.0 — original offline Android robot combat vertical slice.

Install `IRON_VEIL_0.1.0.apk` on an arm64 Android device (API 24+). Landscape.
Godot 4.6.2 / Vulkan Mobile. The x86_64 ABI is included for emulator validation.
This APK uses a debug test certificate; it is not a Google Play AAB.

One complete mission across Relay Yard, Coolant Control and Core Hall, ending
with the Warden encounter and extraction. Original articulated Wraith robot,
shared 1P/3P modes, camera collision/shoulders, three distinct weapons, localized
damage, tactical combat AI, physical/explosive cargo, mechanical disassembly,
touch/gyro/gamepad support, checkpoints and four functional graphics presets.

Validation: 26 logic checks and 24 full-scene runtime checks; Vulkan viewport
captures and wall-clock benchmark; APK signature verification; Android API 35
emulator installation, launcher start, touch deployment/movement, perspective
switch and background/resume. Full logs and measurements are workflow artifacts.
Nothing Phone (3) hardware FPS, real-device gyro and sustained thermals remain
unmeasured. Attached software-rendered desktop numbers do not predict phone FPS.

Art is original procedural industrial/low-poly content, not Frontiers-level AAA
assets. No full campaign, online play, volumetric GI, full destruction or
multi-level humanoid AI navigation. See repository README for exact scope.
